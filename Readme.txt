This plugin is a special plugin to add extra option to your wordpress site.

== Installation ==

1. Unzip the ZIP file and drop the folder straight into your 'wp-content/plugins/' directory.
2. Activate the plugin through the wordpress admin >> 'Plugins' menu in WordPress.
3. For plugin configurations go to settings >> ACh Toolkit
4. Save settings. It's done.
